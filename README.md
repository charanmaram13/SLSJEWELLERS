## ✨ Features

- **Luxury Loading Screen:** Atmospheric dark chocolate loading presentation with gold 3D monogram and *"CRAFTED WITH PRECISION"* transition.
- **Cinematic Hero Experience:** Editorial typography with 3D interactive tilt showcase and ambient gold particles.
- **6 Core Collections:** Dedicated showcases for Gold Necklaces, Traditional Harams, Gold Chains, Elegant Earrings, Bridal Jewellery, and Traditional Jewellery.
- **Interactive 3D Jewellery Runway:** 3D cylindrical stage with mouse drag and touch swipe support, active item lighting, and direct WhatsApp enquiry panel.
- **Artisanal Craftsmanship Storytelling:** 4 stages of jewellery making (Design Inspiration, Precision Crafting, Intricate Detailing, Final Finishing).
- **The SLS Distinction:** Why choose SLS Jewellers highlighting Attention to Detail, Elegant Collections, Traditional Inspiration, and Customer-Focused Service.
- **Editorial Masonry Gallery & Lightbox:** Filter by category (`All`, `Necklaces`, `Harams`, `Chains`, `Earrings`, `Bridal`) with full-screen lightbox and keyboard navigation.
- **Validated Contact & Location:** Direct click-to-call, Google Maps integration, and validated inquiry form with instant WhatsApp dispatch.
- **SEO & Structured Data:** `JewelryStore` schema.org JSON-LD, OpenGraph tags, and custom SVG favicon.

## 🛠️ Tech Stack

- **React.js 18** + **Vite 6**
- **Tailwind CSS 3** (Custom luxury color tokens: chocolate `#2B1D15`, dark brown `#3A281D`, champagne gold `#DCC28F`, warm gold `#C9A062`, ivory `#F6EFE1`)
- **Framer Motion** for animations and 3D spring dynamics
- **Lucide React** for icons
- **Google Fonts:** Cormorant Garamond & Jost

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Build for Production
```bash
npm run build
```
Preview the production build:
```bash
npm run preview
```
